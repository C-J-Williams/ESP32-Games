# ESP32 Games Machine – Documentation

This folder contains supporting documentation and guides for the ESP32 Games Machine project.

The aim is to provide useful information to anyone interested in building, customising or developing their own version of the Games Machine.

The guides cover hardware selection, creating game graphics and producing sound effects for use in the project.

## Documentation Guides

### 1. Hardware
**[Hardware.md](Hardware.md)**

Information about the electronic components used in the Games Machine, including component descriptions, specifications and supplier references.

Covers the hardware required to assemble the project and provides guidance on sourcing suitable components.

### 2. Graphics
**[Graphics.md](Graphics.md)**

A guide to creating and preparing graphics for the Games Machine.

Covers the process of designing, resizing and converting images for use on the ESP32, including game sprites, backgrounds and other graphical elements.

### 3. Sounds
**[Sounds.md](Sounds.md)**

A guide to creating and preparing sound effects for the Games Machine.

Covers audio editing, converting sound files into suitable formats and incorporating sounds into the ESP32 firmware.
