# 3D Printed Enclosure

This folder contains the 3D model files for the games machine enclosure and its components.

### Included Files

- **STL Files** – Ready-to-print models for the games machine case, lid and buttons.
- **FreeCAD Source File** – The original editable FreeCAD project, allowing you to customise the enclosure, modify dimensions or make your own design changes.

### Customisation

The original FreeCAD file is provided so that you can make modifications to suit your own requirements. You can adjust dimensions, alter the design or create customised components before exporting them as STL files for 3D printing.

The STL files are provided for convenience and can be imported directly into your preferred slicer software.

All models are intended for use with the ESP32 Games Machine project.
